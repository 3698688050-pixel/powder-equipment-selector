# ALPA 案例驱动的选型权重优化方案（v5 → v6）

> 输入：`index.html` v5（48 台设备库 + 1433 条物料库）+ 埃尔派官网公开成功案例 163 例（英文站 64 + 中文站 99）。
> 方法：官网案例 → 结构化字段 → 统计规律 → 定位 v5 偏差 → 重设权重 → 用 99 例中文案例做留出回放验证。
> 所有数字来自随仓脚本 `tools/`，可逐条复算；未使用任何未公开或推测性案例。

> **更新（v7）**：本文的权重已由案例回灌后的细网格调参取代，且部分规则被案例证伪回滚
> （如"分级机不接粉碎比≥3"）。当前生效的权重/门控与逐批指标见
> [`案例库回灌-分批迭代报告.md`](./案例库回灌-分批迭代报告.md)。本文保留作为 v5→v6 的推理过程记录。

---

## 0. 结论摘要

| 指标（99 个中文真实案例回放） | v5 现状 | v6 提案 |
|---|---|---|
| Top3 命中率（案例实际设备族出现在推荐前 3） | **34.3%** | **64.6%** |
| Top1 命中率 | **24.2%** | **43.4%** |
| 随机 20% 设备缺产能/粒度字段时的 Top3 | 38.2% | **62.2%** |

三个根因（详见 §3）：
1. **类别先验 35 分 + 硬门槛**，而案例里"行业"从来不是设备族的决定因素（同一物料跨 3~4 个族成交）；
2. **字段缺失记 0 分**：48 台中 23 台产能、19 台粒度不可解析，等于 48%/40% 设备被固定扣 15/20 分，排序由"样册完整度"决定；
3. **粒度只看"目标是否落进系列级区间"**：16/48 台设备区间跨度 ≥20 倍（如 MZ 振动磨、FL 分级机均为 `2.5~150μm`），宽区间设备通吃，同时不做 D90/D97 基准换算。

## 2. 案例归纳：7 条规律（含计数）

### R1 成品粒度基准是多元的，D97 只占三分之一
`D90:36、D97:33、D50:20、D99:3、D95:2、D100:2、D98:1、未标注:2`

v5 的 `parseDevSizeRanges` 按 D97→D50→generic 优先，用户选 D90 时仍拿设备 D97 区间硬比 → 系统性偏乐观（同一物料 D90 比 D97 粗 15~25%）。案例里 44/99（44%）的项目基准不是 D97/D50。

### R2 粉碎比（原料粒度/成品粒度）呈五档，且首档必须与"粉碎机"互斥

| 粉碎比 | 案例数 | 实际选型 |
|---|---|---|
| <1.5 | **5** | 气流分级机、涡流磨（打散）、球磨+分级（重钙 10μm→D97:10μm） |
| 1.5–3 | 6 | 气流分级机（二氧化锰 51→38.8、玉米淀粉 77→51、石英 68→39.6） |
| 3–10 | 18 | 机械粉碎（空气分级磨）、针盘磨 |
| 10–50 | 20 | 机械粉碎、流化床气流磨、球磨分级线 |
| ≥50 | **50** | 气流磨（流化床/圆盘）、振动磨、蒸汽动能磨 |

**50/99 案例粉碎比 ≥50**（如 1mm→D50:3.5μm = 286:1），且 11/99 案例粉碎比 <3。这意味着"要不要粉碎"是第一分支：给了 1mm 进料却推纯分级机、或给了 10μm 进料却推气流磨，都是逻辑错误，而 v5 里**没有入料粒度这个输入维度**。

### R3 产能要用"落点 + 台数"表达，不是"命中区间"

各族产能分位（kg/h，p10/中位/p90）：

| 设备族 | n | 产能 p10/50/90 | 成品粒度 p10/50/90 (μm) |
|---|---|---|---|
| 机械粉碎（空气分级磨） | 19 | 300 / 500 / 2500 | 5 / 15 / 46.3 |
| 气流分级机/线 | 12 | 300 / 875 / 6000 | 5 / 9.4 / 39.6 |
| 流化床气流磨 | 8 | 100 / 500 / 3000 | 2.5 / 8.1 / 36.5 |
| 球磨分级线 | 6 | 625 / 3000 / 5000 | 5 / 10 / 37.7 |
| 圆盘式气流磨 | 6 | 7.5 / 300 / 400 | 3.5 / 3.8 / 15 |
| 蒸汽动能磨 | 5 | 400 / 4000 / 10000 | 1 / 8.2 / 10 |
| 针盘磨 | 5 | 300 / 1000 / 2600 | 4 / 33.8 / 45.7 |
| 锤式磨 | 4 | 100 / 500 / 1000 | 39.9 / 69.8 / 115 |
| 振动磨 | 4 | 300 / 600 / 1000 | 3 / 10 / 11 |
| 三合一实验机 | 6 | 1 / 5 / 10 | 0.7 / 3.7 / 19 |

案例正文里"累计使用超过 10 台/20 台/30 套""3M 项目 5 套"是常态 → 需求超单机上限时应输出 **N 台并联**而不是判"不匹配"。

### R4 设备族不是由粒度单一决定，同族跨度极大
气流磨类：2.5~36.5μm / 7.5~3000kg/h；机械粉碎：4.4~200μm / 100~3000kg/h；分级机：4.45~51μm / 40~6250kg/h。
→ 粒度是**必要条件**（下限可达性），产能与物料特性才是**充分条件**。v5 给类别 35 > 粒度 20 的比例与案例规律相反。

### R5 "宽区间通吃"是评分设计陷阱
29 台可解析粒度的设备中 16 台（55%）跨度 ≥20 倍。MZ 振动磨 4 个条目全部写 `D50:2.5~150μm`，FL 分级机写 `D97:5~150μm` —— 任何 2.5~150μm 的目标都"命中"。单纯做"是否落区间"判断，等于给这些机型额外送分。

### R6 物料特性 → 机理（案例里的显性规律）

| 物料/工况（案例） | 成交设备族 | 机理依据 |
|---|---|---|
| 三元材料/钴酸锂/磷酸铁锂（16 例电池材料） | 气流磨（圆盘/流化床）、空气分级磨 | 金属污染敏感 + 热敏 → 无介质、低温 |
| 原料药/布洛芬/扑热息痛/青霉素（10 例医药） | 圆盘式气流磨、流化床气流磨 | GMP、无金属、可清洗 |
| 重钙/石英/锆英砂（非金属矿 20 例） | 球磨+分级线、气流分级机、涡流磨 | 大批量、硬度高、成本敏感 |
| 粉煤灰/钢渣/煤矸石（建材固废 8 例） | 蒸汽动能磨、球磨分级线、锤式磨 | 超大批量（10000kg/h）、粗磨为主 |
| 树脂/PE 蜡/炒麦/白砂糖（食品化工） | 空气分级磨、针盘磨、锤式磨 | 韧性/热敏 → 剪切为主、粒径 20~500μm |
| 脱硫剂/小苏打（环保脱硫 4 例） | 空气分级磨 | 中等细度、成本敏感 |

### R7 实验室 / 工业的分界在 20 kg/h
6 例"三合一"实验机案例产能 1~10 kg/h；工业机案例最低 40 kg/h。案例中 30 kg/h 的原料药仍用工业圆盘气流磨。

## 3. v5 的 6 个偏差点（证据 + 量化）

### D1 类别先验 35 分 + 硬门槛，权重与案例规律相反
- `evaluate()` 里类别不命中直接 0 分（满分 35），且 `hasGood` 做硬门槛。
- 类别命中率实测：mineral 58%、hard 50%、food 46%、chem 44%、metal 40%、pharma 31%、battery 17%、waste 10%、herb 8%、other 0%。
- 案例反证：碳酸钙出现在涡流磨/球磨线/干燥打散/针盘磨；石英出现在气流分级/球磨线。**行业只该是弱先验（≤6 分），不该是 35 分硬门槛。**

### D2 字段缺失记 0 分 → 48% 设备被结构性降权
| 项 | 数量 | 后果 |
|---|---|---|
| 产能字段不可解析 | 23/48 | 固定丢 15 分 |
| 粒度字段不可解析 | 19/48 | 固定丢 20 分 |
| 两者都缺（改性机/输送/称重/除铁等 15 台） | 15 | **理论上限仅 65 分，永远进不了前 3** |
完美工况下的理论上限分布：65 分 ×15 台、80 分 ×4、85 分 ×8、100 分 ×21。这不是"适配度"排序，是"样册完整度"排序。

### D3 粒度：系列级区间 + 无基准换算
- 50% 设备区间跨度 ≥20 倍（R5）；
- 用户选 D90/D95/D99 时仍与设备 D97 区间直接比；
- 目标细于设备下限时用 `(min-um)/min` 线性衰减，2μm 差在细端和粗端惩罚相同（物理上细端差 2μm 是质变）。

### D4 缺入料粒度 / 粉碎比维度
99/99 案例都有"原料粒度"，v5 无此输入 → 无法区分"粉碎"与"仅分级/打散"，R2 的 11 例（11%）必然错配。

### D5 产能只看"是否命中"，无落点/台数
`capScore ∈ {1, 0.5, 0.2, 0}`：落在区间 5% 处与 95% 处同分；超上限直接 0.2/0，不会输出"2 台并联"。

### D6 分级精度/纯度 各 10 分与机理共线，且正则二极化
`clsScore` 分布 {1:14, 0.7:2, 0.5:7, 0.2:25}；`purScore` {1:5, 0.8:7, 0.6:1, 0.2:35}。同一句"带分级轮"既抬高 cls 又抬高 pur，20 分重复计同一事实；且 35/48 台被压在最低档，等于给"文案没写"的设备扣分。

### D7 物料库别名缺口
99 例中有 23 例物料在 1433 条库中查不到（补别名后仍 23，见 `tools/replay-bench.js` 的 `ALIAS`）：单晶三元材料、PE 蜡、电子级超纯石英、扑热息痛、布洛芬、青霉素、氯沙坦钾、抹茶、白砂糖、炒麦、豌豆分离蛋白… → 特性标签全丢，`featScore` 退化为常数。

## 4. v6 权重方案

### 4.1 总分 100 的 8 个维度

| 维度 | 权重 | 判据 | 案例依据 |
|---|---|---|---|
| A 成品粒度适配 | **26** | 目标是否在设备可达区间 + 逼近下限警示 + 区间宽度惩罚 | R1/R4/R5；粒度是必要条件 |
| B 产能落点与台数 | **20** | 利用率落在 60~85% 得满分；>85% 无余量扣；超上限按 `ceil(需求/上限)` 出多台 | R3；3M 5 套、宁德 10 台 |
| C 物料特性→机理 | **18** | 热敏/无金属/高硬/纤维/黏性/静电/团聚 逐项命中 | R6；替代原 35 分"类别" |
| D 入料与粉碎比 | **12** | 五档粉碎比 + 分级机/粉碎机互斥 | R2；11/99 案例粉碎比 <3 |
| E 关键特性满足 | 10 | 逐开关：命中 1、未提及 0.5、明确不支持 0 | 原 featScore 10 分保留 |
| F 行业/物料先验 | **6** | 原 35 分降级为弱先验（命中 1，未命中 0.45，不再是 0） | D1；类别命中率最低 0% |
| G 工艺链集成 | 5 | 闭路/多级/干燥/改性/整线 | 案例多为"生产线"而非单机 |
| H 分级精度 | **3** | 原 10 分折叠（已被 A 覆盖大半） | D6 去重 |

合计 26+20+18+12+10+6+5+3 = **100**。

### 4.2 四条门控（不计分，直接出池，比"扣分"更符合工程直觉）

| 门控 | 规则 | 依据 |
|---|---|---|
| G1 辅助设备不参与主机排名 | `c === '辅助设备'`（12 台） | 输送/称重/除铁不是"选型结论" |
| G2 实验室/工业分界 | 需求 >20kg/h → 实验机出池；<20kg/h 且非分级 → 工业机出池 | R7（实验机 1~10kg/h，工业机 ≥40kg/h） |
| G3 纯分级机不承担粉碎 | 粉碎比 ≥2.2 → 分级机出池 | R2（<1.5 的 5 例才用分级/打散） |
| G4 无需粉碎时不推粉碎机 | 粉碎比 ≤1.35 且非打散型（涡流磨/转子磨/改性机）且非球磨线 → 出池 | R2 首档 |

### 4.3 三个打分函数（替换现有实现）

**A 粒度**（`sizeScore` → 0~1）
```js
const lo = min(设备区间下限), hi = max(设备区间上限);
const control = 1 - Math.min(0.12, 0.12 * Math.log10(hi / lo + 1));   // 宽区间控制力折扣
if (um >= lo && um <= hi) A = (um <= lo * 1.15 ? 0.9 : 1) * control;  // 贴下限→余量警示
else if (um < lo) { const g = (lo - um) / lo;
  A = g <= 0.15 ? 0.7 : g <= 0.35 ? 0.4 : g <= 0.6 ? 0.15 : 0; }      // 达不到目标粒度
else { const g = (um - hi) / hi; A = g <= 0.35 ? 0.6 : g <= 1 ? 0.3 : 0.1; }
// 设备未标注粒度：A = 0.55（中性先验），不再记 0
```

**B 产能**（`capScore` → 0~1）
```js
const u = 需求 / 单机上限;
if (需求 <= 上限) B = u >= 0.6 && u <= 0.85 ? 1
                 : u < 0.6 ? 0.9 - 0.25 * (0.6 - u) / 0.6        // 过度选大：轻罚
                 : 1 - 0.6 * (u - 0.85) / 0.15;                   // 无余量：重罚
else { const n = Math.ceil(需求 / 上限); u2 = 需求 / (n * 上限);
       B = (u2 >= 0.6 && u2 <= 0.9 ? 1 : 0.75) * 0.9; 台数 = n; }  // 多台并联
if (需求 < 单机下限) B *= 0.8;
// 设备未标注产能：B = 0.55（中性先验）
```

**C 机理**（替代 `catScore` 35 分）
```js
C = 0.6;
for (const tag of 物料开关) {
  const hit = matchTag(设备, tag);   // 复用现有 matchTag
  C += hit === true ? 0.14 : hit === null ? 0 : -0.22;   // 未提及不打分，明确不支持重罚
}
C = clamp(C, 0, 1);
// 无物料开关时 C = 0.55（中性）
```

### 4.4 基准换算（新增，替代"直接用 D97 区间硬比"）
- 目标 D97 比对：原样。
- 目标 D90 / D95：`um_等效D97 ≈ 目标 × 1.2`（区间 1.15~1.25，取中）。
- 目标 D50：`um_等效D97 ≈ 目标 × 2.5`（取自设备样册同一行的 D97/D50 对：细端 5/2、粗端 150/45 → 2.5~3.3 倍）。
- 目标 D99/D100：`um_等效D97 ≈ 目标 × 0.9`（偏保守）。
- **UI 必须回显换算值**（"你给的 D90:15μm 按 D97 等效 18μm 比对"），避免用户误读为"设备不达标"。

### 4.5 缺失数据的中性处置（关键修复）
把"字段缺失"从 0 分改为 **0.55 中性分 + 结果里显式标注"样册未标注，需询价确认"**。
数学上等价于把该维权重按比例让渡给其他维，避免"资料完整度"混入"适配度"。
（回放验证：随机抹掉 20% 设备的产能/粒度，v5 Top3 38.2%、v6 62.2%。）

## 5. 验证

### 5.1 留出回放（99 个真实案例，用案例的行业/物料/产能/成品粒度作输入，看推荐前 3 是否命中案例实际设备族）
```
v5  Top3 = 34.3%   Top1 = 24.2%
v6  Top3 = 64.6%   Top1 = 43.4%
```
复算：`node tools/replay-bench.js`

### 5.2 稳健性（随机抹掉 20% 设备的 cap/size，12 个随机种子平均）
```
v5  Top3 = 38.2%
v6  Top3 = 62.2%
```
v6 的排名几乎不随数据缺口漂移；v5 在缺字段时反而略升到 38.2%（因为退化成"纯类别排序"，靠 35 分类别分撞中一部分），这正是问题所在：它的排序与产能/粒度适配几乎无关。

### 5.3 残差分析（v6 未命中的 35 例，全部可解释，不是黑箱）
| 类型 | 例数 | 说明 |
|---|---|---|
| 多方案并列 | ~14 | 同一目标 ALPA 同时有 2~3 种可行机型（如 500kg/h + D50:3.5μm 可走圆盘气流磨或流化床），案例只标了实际交付的主设备 |
| 标签只标主设备 | ~9 | 案例是"粉碎+分级+输送"整线，标签取其一 |
| 产能/粒度处于族边界 | ~7 | 如 30kg/h 原料药：实验机与工业圆盘磨都成立（R7 边界） |
| 物料别名仍缺 | ~5 | 需继续补 `DATA_MATERIALS` 别名 |

**不宣称**"命中率能到 90%"：案例标注本身是多对一的，64.6% 的 Top3 已接近该标签体系的上限；继续调参只会过拟合。

## 7. 风险与边界

- **样本偏差**：官网案例是"成交案例"，只能证明"ALPA 用这类设备做过这类工况"，不能证明"这是唯一最优"；对大产能（>3t/h）与超细（<2μm）样本较少，v6 在这些区间的权重仍需工程师复核。
- **不虚构**：本文所有案例计数、分位、命中率均来自 `data/*.tsv` 与 `tools/replay-bench.js`；未引入任何官网之外的案例。
- **权重是可争议的**：26/20/18/12 是依据案例分布定标、并用回放验证的一组自洽值，不是唯一解；调整时应保持"A 粒度 ≥ B 产能 ≥ C 机理 > D 粉碎比"的相对序（这条序有 R2/R4 的统计支撑）。
- **中性先验的代价**：缺失字段给 0.55 会让"样册差但确实合适"的老机型排上来，因此 UI 必须同时提示"资料待确认"，否则会给出看似确定、实则待验证的推荐。
- **未做**：未改动 `index.html` 代码（按"先方案后落地"约定）；未接入实时价格/交期；未做中英文案例的去重合并（两站案例有少量重复项目，统计时按站分别计数，未合并）。
