# 粉体设备预选型（完整版）

三版合一的完整版本：**复合配方加权比配 + 物料自动匹配 + 完整数据库**。

## 功能

- **加权比配算法**：按物料属性（硬度 / 含水率 / 密度等）对候选设备做复合配方加权打分，输出推荐排序。
- **物料自匹配**：输入物料自动匹配到合适的粉体设备型号。
- **完整数据库**：内置 **1433 种物料** 与 **48 个系列设备** 及映射表。

## 来源

由以下三个版本合并而成：

| 版本 | 来源 | 贡献 |
|------|------|------|
| 复合配方加权版 | [`pre`](https://github.com/3698688050-pixel/pre) | 加权比配算法 |
| 物料自动匹配版 | [`Pre-selector`](https://github.com/3698688050-pixel/Pre-selector) | 物料自匹配 |
| 桌面版（极简开关版） | 本地 `powder-equipment-selector` | 1433 物料 + 48 设备数据库 |

## 使用

单文件自包含（数据已内联），直接打开 `index.html` 即可，或访问在线地址：

https://3698688050-pixel.github.io/powder-equipment-selector/

本地预览：

```bash
npx serve .        # 或任意静态服务器
```
